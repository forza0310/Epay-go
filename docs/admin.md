# 管理员服务

internal/admin 提供唯一管理员的创建、密码与 TOTP 验证、会话检查、退出登录和验证器恢复。通过 Repository 接口调用仓储，通过 securebox.Box 加密绑定密钥；不依赖 HTTP、Vault 或具体数据库驱动。SQLite 已有仓储实现该接口。

## 职责与边界

- Initialize 检查密码格式和新验证器的动态码，然后创建唯一管理员；不会覆盖已有管理员。
- Login 先记录登录尝试并检查限流，再校验密码和动态码。成功后生成登录与 CSRF 令牌，通过仓储事务记录动态码已使用、创建会话及登录事件。
- ValidSession 和 ValidCSRF 检查服务端会话是否有效、表单令牌是否与会话匹配；服务层不读取 Cookie，不直接拦截 HTTP 请求。
- Logout 删除指定会话。ResetTOTP 要求管理员密码和新验证器动态码；保存新绑定时撤销全部旧会话，仓储条件更新防止覆盖并发修改。
- VerifyRecoveryPassword 为本地恢复流程提供密码检查；服务层不负责终端交互。主密钥由调用方提供，密钥文件管理不属于本包。

本次交付为服务模块。HTTP 鉴权中间件、页面与二维码、命令行恢复入口、程序启动接入均独立交付；仅有此模块不代表已开放后台登录接口。

## 安全规则与选择

密码须为 10–1024 字节的有效 UTF-8 文本，使用标准库 PBKDF2-SHA256，600,000 次迭代、16 字节随机盐和 32 字节哈希。保存算法参数、盐及哈希，不保存明文密码。初始化与登录共用两个密码计算名额，名额占满时返回带等待时长的限流错误。

TOTP 采用 RFC 6238：160 位随机绑定密钥、SHA-1 HMAC、6 位、30 秒周期，允许前后各一个周期。绑定密钥通过 AES-GCM 加密，以 admin:totp:1 区分用途。已使用及更早周期的动态码不能再次登录，初始化和重置时验证的周期也会被记录。

会话有效期固定为 12 小时；登录令牌与 CSRF 令牌各使用 32 字节随机数据，数据库只保存 SHA-256 哈希。重启后有效会话可以继续使用；退出、重置绑定或过期会使会话失效。持久化会话便于服务端撤销，代价是检查会话需要访问仓储。

登录次数限制与动态码防重放由仓储持久化，防止重启绕过。密码和动态码检查发生在写事务之前；提交时再次核对密码哈希、绑定密文和已用周期，避免验证后数据被并发修改。错误通过返回值交给调用方，本包不记录敏感值、不设置浏览器 Cookie、不启动后台任务。

## 验证范围

service_test.go 使用临时 SQLite 数据库验证密码长度和编码规则、RFC 已知动态码、并发重复登录拒绝、会话跨重启保留、绑定恢复、退出及过期。没有真实支付或生产数据操作。
