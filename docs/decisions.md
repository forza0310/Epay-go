# 关键设计决策

## ADR-001：Go 与工具链

状态：用户指定。使用本机 Go 1.27.3，设置 GOTOOLCHAIN=local，禁止构建时自动下载其他版本。

理由：遵循用户明确的开发版本选择。SQLite 驱动固定版本，校验记录随代码提交。代价：此版本不等于研究时查询到的最新补丁版；正式发布前需核对已知漏洞与修复要求，再由用户决定版本变更，不能宣称所有最新安全补丁已包含。

## ADR-002：单管理员、直接收款

状态：用户指定。唯一管理员管理自己的多个通道，保留 PID 仅用于外部协议兼容。

理由：业务不涉及平台结算。省去多租户、余额账户、手续费和分账。仍需保存到账流水，用于审计与防重复发货。

## ADR-003：编译式插件与功能移植

状态：已确认。插件随主程序编译发布；第一个插件为 alipaycode 的 Go 移植。构建时扫描约定目录，生成显式导入和构造代码，由 builtin.NewRegistry 统一装配。新增插件不再修改 app.New。

理由：保留收款流程，降低原 PHP 全局状态和运行环境耦合。生成代码保留静态类型检查、可审查的导入关系与显式构造，不依赖 init 自注册和可变全局注册表。代价：新增插件需要重新生成、构建和发布；生成文件须与插件源码一起提交，普通 go build 不自动执行生成。不能直接运行原 PHP 文件。只有明确需要动态安装时，再评估进程隔离的插件协议。

## ADR-004：标准库 HTTP、SQLite、单进程

状态：SQLite 持久化与加密模块已实现；管理员用例、启动接入及支付 worker 另行交付。使用 modernc.org/sqlite v1.62.0 纯 Go 驱动，单连接、WAL、外键、busy timeout 和 FULL 同步；当前不支持多实例。

以嵌入的 migrations/*.sql 为唯一结构定义，迁移逐版本事务提交，拒绝未知版本，不自动降级。数据库目录私有，文件在交给驱动前限制为 0600。管理员仓储只依赖独立 Credentials 数据结构，不引入密码或 TOTP 验证用例。

通道配置使用外置 32 字节主密钥和 AES-256-GCM，加密时绑定用途及对象标识。仓储只接收配置密文，元数据列表不回显凭证；主密钥校验值只首次写入，后续必须能解密旧校验值。主密钥与数据分开备份，当前不提供密钥轮换工具。

理由：单人使用无需 Redis、消息队列或大型框架；将 SQL、事务与加密边界隔离，便于独立审核和测试。代价：写入串行、迁移需维护版本，应用启动和备份流程须遵循单实例约束。

## ADR-005：ZPAY 协议隔离

状态：用户要求兼容，差异在 API 文档明确。外部 MD5、PHP 路径与 DTO 仅存在于协议/HTTP 层；内部保持金额与状态强类型。

理由：兼容调用方，不让历史协议决定内部模型。MD5 不扩散到密码、会话或新设计的加密逻辑。ZPAY 平台余额及专属小程序不具有可直接复制的业务实体。

## ADR-006：余额语义与预登记回调

状态：待确认。余额建议定义为未托管资金 0.00；当前返回未实现。后台预登记允许的 notify_url 和 return_url，支付请求只能选择匹配地址。

理由：不创造不存在的账户余额，并控制服务端通知的访问范围。代价：比任意回调 URL 更严格；新增自有业务地址需管理员登记。

## ADR-007：仅为高价值边界保留测试

状态：遵循用户工程要求。测试覆盖签名、金额、插件发现、配置加载、迁移、持久化及加密完整性等关键边界。

理由：验证真实失败模式，不为每个结构体、getter 或占位函数增加测试。后续支付确认、鉴权、恢复和幂等属于高风险逻辑，应随实际实现增加必要测试。

## ADR-010：自动加载工作目录 .env

状态：用户明确要求直接读取启动工作目录的 .env，不查找父目录、go.mod 或可执行文件目录。已有环境变量优先于文件值，文件值优先于默认值。显式空环境变量同样优先，不隐式回退到文件中的密钥。

理由：让终端与 IDEA 共用配置，同时保留部署环境覆盖能力。使用标准库实现有限的单行语法，不执行 shell、不插值变量，不将密钥写入进程全局环境。文件缺失允许环境变量部署；文件存在但无法读取、重复定义或格式错误时明确失败，错误不回显值。代价：不提供完整 shell/dotenv 扩展语法；相对数据库路径仍以启动工作目录为准，加载文件不改变工作目录。
